# TLA+ By Example in VS Code

This codespace has the TLA+ extension, Java for TLC, every lesson in `lessons/` and the tlaplus/Examples specifications in `Examples/`.

## Run the spec from the website

1. On the website, click **Run in VS Code** (next to **Run TLC**). It copies a command.
2. Wait until this codespace has finished setting up (the first start takes a few minutes).
3. Open the terminal with <kbd>Ctrl</kbd>+<kbd>`</kbd>, paste the command and press <kbd>Enter</kbd>.

Your spec opens in the editor under `playground/` and TLC runs in the terminal.

## Model-check any spec

Open a `.tla` file (with a `.cfg` of the same name next to it) and run **TLA+: Check model with TLC** from the Command Palette (<kbd>Ctrl</kbd>/<kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>P</kbd>) for the interactive results and error-trace view.

When you are done, stop the codespace (Command Palette: **Codespaces: Stop Current Codespace**) so it does not use up your free hours.
